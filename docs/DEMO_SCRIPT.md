# Six-minute local demo walkthrough

**Prerequisite:** A separate Veritas PostgreSQL project is configured in ignored `backend/.env`, reviewed SQL has been applied manually through revision `0003_comparison`, `/health` reports `database_ready: true`, and both local services are running. Until then, the live three-case walkthrough is blocked. All company names and documents below are fictional.

| Time | Exact action | What to point out |
| --- | --- | --- |
| 0:00–0:35 | Open `http://127.0.0.1:5173/`; select **Live API**. | The promise is separate from supplied policy documents. The comparison uses a deterministic bounded wording adapter, not hosted AI. |
| 0:35–1:35 | In **Try a fictional subscription case**, choose **Promise holds up**, then **Compare documents**. Open the claim's **Inspect evidence** link. | “Cancel at any time” and “Access continues through the end of the paid month” are exact cited clauses with document IDs and versions. Result: consistent *within these documents*. No refund promise is inferred. |

Highlight “only if the service has never been used” in the fictional refund policy. The original promise and human rationale remain visible. The strict Guardian keeps the output held after review. |
| 3:15–4:45 | Return to Claim Court. Choose **Cannot be resolved** and **Compare documents**. Open the claim, then **Review claim**. Choose **Still uncertain**, enter rationale “The supplied documents explain cancellation but not refund eligibility,” and **Save review**. Open Guardian. | The policy supports cancellation but says nothing about refunds. Result: insufficient evidence; missing evidence is not proof of deception. The review persists and Guardian remains held. |
| 4:45–5:35 | Reload an inspected claim and Guardian; show the review history and latest backend action. | Machine comparison, human decision, and release action are separate. The deterministic result only describes supplied written terms; it does not establish legal enforceability or actual company practice. |

If a provider fails, the supplied-document comparison still uses the local deterministic adapter. If PostgreSQL is unavailable, the live UI displays an error; switch explicitly to **Synthetic demo** only as a labeled interface fallback, never as a substitute for the three-case live demonstration. |
